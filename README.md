# Задачи для модуля "Базовый синтаксис. Типы"

Проект собран как многомодульный Maven-проект: каждая задача — отдельный модуль `taskNN`.

## Структура модуля

```
taskNN
├── pom.xml
├── README.md                                   описание задачи
└── src
    ├── main/java/com/example/taskNN/TaskNN.java исходный файл, который нужно модифицировать
    └── test/java/com/example/taskNN/Tests.java  автоматические тесты
```

## Сборка и запуск тестов

Проверить все задачи:

```
mvn test
```

Проверить одну задачу:

```
mvn -pl task01 test
```

Тесты проверяют только формальные признаки выполнения задачи
и не заменяют проверку качества выполнения преподавателем.
